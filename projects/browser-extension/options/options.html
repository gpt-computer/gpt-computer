gpt-computer Assistant — Settings

Connect the extension to your local gpt-computer server.

Account — gptc.space

Sign in to sync conversations across devices via your server's /v1/secret/conversations endpoints (AES-256-GCM encrypted at rest).

Server

Defaults to the public https://gptc.space instance. For a local server run python -m gptc --port 1337 and enter http://localhost:1337.

Sent as Authorization: Bearer … and gptc-api-key.

Browser as CDP provider

Let your gptc server drive this browser (automation tabs via chrome.debugger) instead of launching its own headless Chrome. Requires a local gptc server with GPTC_BROWSER_MODE=extension.

Chat defaults

Loaded from /v1/models. Leave empty to let the server pick.

Images

Generate images from the side panel with /img your prompt.

Context & behavior

Quick actions

Shown as buttons in the popup. {text} is replaced with the selection/page content.
